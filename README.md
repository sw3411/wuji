# 物迹（Wuji）— 个人物品管理与价值追踪 App

> 看见自己拥有什么，知道物品放在哪里，理解每一次消费的长期价值。

「物迹」是一款**本地优先**的个人物品管理 App：记录你买过什么、花了多少钱、放在哪里、用了多少天、每天摊多少钱、转卖后实际损耗多少。不需要注册登录，数据保存在本机，随时可备份迁移。

它不止是「物品台账」，而是围绕三件事展开：

- **记录**：物品 / 树状位置 / 生命周期事件 / 转卖记录，一条不落；
- **度量**：日均成本、保值率、四维价值评估、透视统计表，把「值不值」算清楚；
- **决策**：月度预算预警、重复购买提醒、AI 购买评估、AI 二手估价，在你下一次剁手之前先问一句「真的需要吗」。

支持 Android / iOS，手机竖屏优先，兼容深色模式，界面为简体中文（架构已为国际化预留扩展点）。当前以 Android APK 交付（iOS 架构兼容，尚未做签名打包）。

## 功能列表

### 物品与位置
- **物品管理**：添加 / 编辑 / 删除（软删除进回收站，默认保留 30 天，可恢复 / 永久删除）
- **物品信息**：封面图 + 多图 + 票据图、品牌、型号、数量、渠道、商家、订单号、标签、备注、保修（月数或截止日）、**保养周期**、**使用频次**（六档：每天 / 每周数次 / 每周 / 每月 / 每季 / 偶尔，自动折算每月使用次数）
- **六维评分雷达**：质量 / 实用 / 颜值 / 情感 / 刚需 / 频率，自绘雷达图 + 加权总分
- **分类**：22 个内置分类（手机数码、家用电器、家具家装、服装……），支持自定义分类（图标 / 颜色 / 排序），系统分类只能隐藏不能删除
- **树状位置**：家 → 卧室 → 衣柜 → 第二层；**23 个预设位置图标**（客厅 / 厨房 / 书房 / 车内 / 仓库……）+ 按名称自动匹配；**同级重名校验**（同父下不允许重名，跨层级允许）；位置照片与说明、位置下物品统计
- **状态管理**：使用中 / 闲置 / 收纳中 / 已借出 / 维修中 / 已消耗 / 已丢失 / 已丢弃 / 已转卖 / 已赠送（受控枚举）
- **生命周期事件**：购买 / 移动 / 维修 / 保养 / 借出 / 归还 / 转卖 / 赠送 / 丢弃 / 丢失 / 自定义，详情页时间线展示
- **统一转卖流**：从任何入口选择「转卖」（详情页 / 事件表单 / 状态切换 / 盘点处置）都会强制填写金额与日期，自动生成 / 更新转卖记录与事件，净收入一目了然
- **盘点模式**：按范围（全部 / 某位置）逐件核对「还在吗」，顺手处置丢失 / 丢弃 / 送人的物品，最后给出盘点总结
- **列表能力**：卡片 / 紧凑视图、搜索（名称 / 品牌 / 型号 / 备注 / 标签 / 位置）、**五维筛选**（分类 / 状态 / 价格档 / 标签 / 位置）、9 种排序、多选批量移动 / 改分类 / 删除；筛选条件持久保留

### 价值度量
- **基础指标**：使用天数、当前日均成本（**逐件之和口径**）、转卖净收入、实际损耗、保值率（集中在 Calculator 服务，全部有单元测试）
- **四维价值评估**（详情页）：**成本 ×35 + 使用频次 ×30 + 使用时长 ×20 + 品类刚需 ×15**——车和家电成本高但属刚需品类不会被误判，珠宝收藏属悦己品类权重另算；结论四档：超值 / 物有所值 / 一般 / 不划算
- **单次使用成本**：总价 ÷（频次 × 持有月数），「这台咖啡机每杯摊多少钱」
- **统计透视表**（洞察页）：分类 / 位置 / 状态三维度 × 9 项指标（总件数、总金额、年新增件数 / 金额、同比差、月新增件数 / 金额、环比差）；**首行首列冻结可双向滑动、表头点按排序、环比红涨绿跌、无基数按全额变动显示**

### 防剁手闭环
- **月度预算**：设置月度购入预算，进度卡 80% / 100% 变色；**保存新物品即时预警**（本月已花 + 本单金额 vs 预算）
- **重复购买提醒**：DuplicateFinder 综合同名 / 名称包含 / **AI 标签命中** / 关键词二元组 / 品牌相似度打分，在添加表单与购买评估时提示「你可能已经有类似的」
- **AI 购买评估**：输入想买的名称 / 预期价格 / 使用期限 / 频次，AI 结合本地已有物品给出「该买 / 不该买」+ 匹配度 + 理由 + 替代建议；本地先算单次成本，并实时列出相似物品

### AI 能力（OpenAI 兼容接口，自行配置，不配置不发送任何数据）
- **快速添加**：一句话或**拍照识别**（多模态）→ 结构化预填 → 确认保存；支持**一句话批量添加多件**（「蓝牙耳机、加湿器和一个鼠标垫」→ 多卡预览，一键保存 N 件）
- **AI 助手对话**：自然语言问答（「我最贵的东西是什么」）；AI 可调用 5 只读工具查本地数据，写操作（改名 / 删除等）需你在界面上确认才执行
- **每日 AI 诊断**：首页「近期状态」卡，综合体检 / 预算 / 保养给出建议
- **九维洞察**：从攒物习惯到闲置风险的综合分析
- **AI 周报 / 年度账单**：周一自动去重生成周报；年度账单（全年花费 · 最贵一笔 · 转卖回收 · AI 年度总结），可分享
- **AI 二手估价**：详情页一键评估当前合理转卖价
- **每日 AI 打标**：自动为物品打五类标签（品类 / 品牌 / 系列 / 同义 / 用途），喂给重复检测与检索，越用越准

### 数据与安全
- **应用锁**：生物识别（指纹 / 面容）或锁屏密码解锁，可开关；解锁后短暂豁免防止切后台回来被重复锁
- **AI API Key** 存入系统钥匙串 / Keystore（flutter_secure_storage）
- **备份恢复**：单文件 JSON 备份（含图片 base64）、版本与完整性校验、覆盖 / 合并两种恢复方式、恢复前自动临时备份
- **导出**：CSV 物品清单、JSON 完整备份（系统分享）
- **其他**：首次启动引导、表单草稿自动保存（App 被杀后可恢复）、深色模式、图片清理（只清理无引用图片）、保修 + 保养双通道本地通知提醒、回收站超期自动清理、删除物品 5 秒内可撤销、超过 14 天未备份时首页提醒

## 设计说明

当前视觉版本：**v12.3「鲜薄荷规格表 + 玻璃悬浮」**。

- **色彩**：鲜薄荷双层绿——图形级 `#21A36B` / 文字级 `#17724B`（白底对比度 5.9:1）/ 按钮级深绿；深色模式为**暖夜**（`#3B3535` 家族暖灰）+ 提亮绿（`#3FBF82` / `#57CF97`）；AI 对话气泡双色（我方深绿染玻璃 / 对方浅薄荷）
- **画布**：全局渐变画布（浅色 = 右上纯白 → 左下微暖）+ 两团径向环境色斑，为毛玻璃提供折射内容；scaffold 透明透出渐变
- **玻璃体系**：底部导航为**悬浮毛玻璃胶囊**（两侧留边 + 圆角 + 背景模糊 + 轻投影），金刚位与物品卡为真 BackdropFilter 磨砂卡片（GlassCard：投影 + 圆角裁切 + blur + 光泽渐变面 + 白发丝边）
- **首页档案卡**：深色绿染玻璃，件数大数字居中，总成本 / 本月新增 / 日均成本三指标三等分各自居中
- **图标徽章**：位置与物品占位图标统一为薄荷 tint 渐变底 + 同色边框 + 主题色图标，规避「灰色默认图标」的廉价感
- **字阶**：全局小一档（正文 13.5 / 卡题 14 / 页题 15.5），大数字细字重 + 等宽数字，克制而非粗黑

## 技术栈

| 用途 | 选型 | 说明 |
|---|---|---|
| 框架 | Flutter 3.32+ / Dart 3.8 | |
| 状态管理 | flutter_riverpod | |
| 路由 | go_router（StatefulShellRoute） | 五栏分支 + 嵌套 Navigator |
| 数据库 | Drift + sqlite3_flutter_libs | 类型安全 SQL ORM，schema 版本迁移（当前 **v6**：六维评分 → 保养月数 → 使用频次 → aiTags → 位置图标） |
| 图片 | image_picker（拍照 / 相册，内置压缩参数） | 保存到 App 私有目录 |
| 格式化 | intl | 日期 / 货币 / 本地化 |
| 图表 | fl_chart + 自绘雷达 / 矩形树图 / 透视表 | |
| 分享导出 | share_plus、file_picker | 备份导出 / 导入 |
| 通知 | flutter_local_notifications + timezone | 保修 / 保养双通道提醒（保存物品自动调度，恢复备份后重排） |
| 应用锁 | local_auth | 生物识别 / 锁屏密码，需 FragmentActivity |
| 密钥存储 | flutter_secure_storage | AI API Key 存入钥匙串 / Keystore（minSdk 23+） |
| AI | http（OpenAI 兼容 `/chat/completions`，支持多模态 image_url） | OpenAI / DeepSeek / GLM / Ollama 通用 |

领域模型采用手写 `copyWith` + `toJson/fromJson`（未用 freezed，减少代码生成复杂度，Drift 仍使用 build_runner）。金额全部使用**最小货币单位（分）整数**存储，杜绝浮点精度问题。

## 项目架构

```
lib/
  app/                  应用层：主题、路由、Provider 装配、底部导航、全局设置、图片仓库
  core/
    ai/                 AI：配置、OpenAI 兼容客户端、Prompt 模板、解析服务（parseItems / 估价 / 周报 / 打标…）
    constants/          产品名、内置分类、位置图标集等常量（集中配置）
    notifications/      本地通知服务
    utils/              金额、日期格式化
  data/
    db/                 Drift 表定义与数据库（行 ↔ 领域对象映射，schemaVersion=6）
    repositories/       Item/Location/Category/Sale/Settings 仓库 + 备份服务
  domain/
    models/             纯数据模型（Item、Location、Category、SaleRecord、ItemEvent、枚举）
    services/           业务计算：ItemCalculator、StatisticsService、PivotStats、ItemFilter、DuplicateFinder、ItemRetrieval
  features/
    onboarding/ home/ items/ locations/ statistics/ settings/ ai/
  shared/widgets/       通用组件（GlassCard、场景卡、雷达图、状态徽标、应用锁门卫等）
```

分层原则：**页面不写业务计算**——天数 / 日均成本 / 保值率走 `ItemCalculator`，统计口径走 `StatisticsService`，透视表走 `PivotStats`（纯函数），筛选排序走 `applyItemFilter`，重复检测走 `DuplicateFinder`；仓库负责持久化，Provider 负责状态装配。

## 数据库结构（ER）

```
items ─┬─> categories.id        （冗余 categoryName 快照，分类改名不影响历史记录）
       ├─> locations.id         （冗余 locationName / locationImagePath；locations.icon 存预设图标键）
       ├─  maintenanceMonths / usageFrequency / scores(六维) / aiTags(JSON)
       └─< sale_records.item_id （一件物品最多一条转卖记录）
       └─< item_events.item_id  （一件物品多条生命周期事件）
locations.parent_id ─> locations.id   （树状自关联，同级重名校验在仓库层）
settings(key, value)                  （键值设置：偏好、AI 配置、筛选器、草稿、预算、轮播等）
```

字段与软删除（`deletedAt`）细节见 `lib/data/db/tables.dart`。金额字段（`purchasePrice`、`salePrice`、运费、手续费等）均为 int 分。

## AI 功能配置

1. 进入「设置 → AI 助手设置」
2. 填写：
   - **API 地址**：如 `https://api.openai.com/v1`、`https://api.deepseek.com/v1`、`https://open.bigmodel.cn/api/paas/v4`，本地 Ollama 填 `http://localhost:11434/v1`
   - **API Key**：你的密钥（仅保存在本机钥匙串）
   - **模型名称**：如 `gpt-4o-mini` / `deepseek-chat` / `glm-4-flash`（拍照识别需多模态模型）
3. 点击「测试连接」验证，保存即可使用

隐私：AI 功能会把相关物品数据发送到**你配置的** API 服务商；不配置则完全不发送任何数据。

## 数据备份格式

备份为单个 JSON 文件（扩展名 `.wuji.json`）：

```json
{
  "app": "物迹",
  "format": "wuji-backup",
  "version": 1,
  "exportedAt": "…",
  "items": [...], "locations": [...], "categories": [...],
  "saleRecords": [...], "itemEvents": [...],
  "settings": {...},
  "images": { "文件名": "base64…" }
}
```

恢复时校验 `format` 与 `version`（高版本备份拒绝恢复），支持覆盖 / 合并；恢复前自动把当前数据写入临时备份，失败可回滚。

## 已知限制

- 备份文件包含图片 base64，物品很多时文件较大（几百 MB 级别导出较慢）
- AI 解析依赖模型的 JSON 输出能力，弱模型可能解析失败（已做容错提取与降级）
- 多币种支持按记录维度存储，统计页汇总仍按单一货币展示，不做汇率换算
- 通知提醒在 App 被强制结束后由系统调度，Android 部分厂商需允许自启动
- 平板为基础适配（布局可用，未做双栏优化）
- iOS 端架构兼容但未做签名打包与真机验证
